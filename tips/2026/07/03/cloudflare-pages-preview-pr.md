# Cloudflare Pages (3/6): previews por PR y rama

Despliegue de frontends Angular en Cloudflare Pages.

---

## Por qué Pages

Builds en la nube, previews por rama y CDN global sin gestionar servidores.

---

## Build típico Angular

```bash
npm run build
# Salida habitual: dist/<app>/browser
```

Configura en el panel de Pages el directorio de salida y el comando de build según tu `angular.json`.
