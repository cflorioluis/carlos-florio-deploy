# Performance budgets en el build de Angular

Angular 22 consolida signals, recursos HTTP y tooling moderno (Vitest, MCP).

---

## Qué llevarse

- Revisa el changelog oficial y prueba en una rama.
- Prioriza migraciones de detección de cambios y HTTP si vienes de v21.
- Mide el bundle antes y después del upgrade.
